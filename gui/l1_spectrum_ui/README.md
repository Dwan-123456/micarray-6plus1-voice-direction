# 独立 L1 Spectrum UI

本界面是与 Development Test UI 平行的 L1-only 观察工具。启动后只创建 UAC 麦克风输入、通道校准、
Ingest、IMCRA、可选 IMCRA 预降噪和 L1 电平/频谱分析，不创建 WindowAssembler、L2、L3、L5、
正式录音或数据管理服务。

## 启动

在项目根目录运行：

```powershell
.\scripts\launch_l1_spectrum_ui.ps1
```

界面启动后每1秒自动扫描配置中的麦克风，不要求设备在程序启动前已经接入。未发现设备时界面正常
保持运行，不弹出启动错误窗口，左上显示红色“未连接”；识别并成功打开后自动开始采集并切换为绿色
“已连接”。采集中设备停止提供音频时会回到自动扫描状态。连接状态按键只作显示，不执行手动连接或
停止操作。逻辑通道与项目现有6+1契约一致：`MIC0`～`MIC5`为六个环形麦，`Center`是第七个物理麦，
`Mix`是硬件混音；默认观察`Center`，任一时刻只能选择一个通道。

桌面快捷方式直接调用`.venv\Scripts\pythonw.exe`，启动时不创建控制台黑框；主窗口默认最大化显示。
PowerShell启动脚本也以独立隐藏的`pythonw`进程启动界面，不等待GUI退出。

每次麦克风成功连接后，界面会尽力发送一次官方关灯命令`e`；麦克风未连接时不会访问CDC，默认关灯失败也不会弹出错误。手动点击灯光开关时仍正常报告串口故障。

## 四个区域

- 左上：红/绿麦克风连接状态、IMCRA预降噪开关、CDC灯光开关、八路20 ms RMS电平和观察通道选择。
- 右上：所选通道当前20 ms输入的2048点FFT柱状频谱，横轴固定0～10 kHz，每个新L1块刷新一次。
- 左下：所选物理麦的当前IMCRA噪声PSD、噪声/信号/SNR/SPP数值；`Mix`没有独立IMCRA估计。
- 右下：点击右上“抓拍到右下”时复制并冻结的输入频谱及权威sample/sequence标识。

当前输入频谱与IMCRA噪声谱都换算为便于对照的单频点dBFS显示；IMCRA顶部数值仍采用正式
`ImcraHopSnapshot.noise_features`原始统计口径。
