# Development Test UI v1.5.1

界面只连接真实Sipeed麦克风。固定820 px左列上方显示8路电平、7路P1和阵列P2，左列下方显示P2 Gate、MUSIC设置和方向ID表；右侧使用尺寸稳定的独立正方形显示360° MUSIC角度图。右下角空白区域以不参与布局尺寸协商的overlay显示“启用声源数估计”“MUSIC阶数使用估计结果”、`突出声源数：0/1/2`和当前阶数。估计默认开启并在Gate关闭时继续更新；关闭估计会同时关闭阶数跟随并恢复固定2阶。跟随开启后，预热时计数显示`—`但当前阶数为1，计数0/1使用1阶，2及以上使用2阶；故障、关闭估计、过期或快速重启后的旧结果显示`—`。L3～L6区域已删除。

最底部性能栏与上述控制框分离。性能监控可实时开关，每1秒刷新上一秒IMCRA、P、声源数估计耗时/帧率/故障率、MUSIC、ID、总耗时、输出/实算帧率、排队时间与自适应周期；关闭即清空，不保存历史。
