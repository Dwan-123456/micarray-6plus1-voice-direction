# Layer 1 v1.4

L1只负责真实8通道设备输入、通道校准、灯控和7物理麦IMCRA。每20 ms直接对960个真实样本执行960点FFT，不补零；0～10 kHz输出为50 Hz间隔的201个频点。每跳更新逐麦P1、阵列P2（P1中位数）和逐麦噪声PSD；可选Wiener预降噪同步使用20 ms分析帧、10 ms步长和960点FFT，通过50%重叠sqrt-Hann WOLA仍按20 ms发布完整音频块。v1.4不维护7×7空间噪声协方差。CountNet、HTTP、录音、回放和独立频谱UI已删除。

P1使用办公室与诊室统一配置的250～600 Hz逐bin加权：250、300、350、400、450、500、550、600 Hz权重依次为16.1502%、18%、18%、18%、16.3814%、8.8159%、4.1165%、0.5360%；P2取7个物理麦P1的中位数，供L2 Gate使用。Gate默认阈值0.80保持不变。运行时音频最多在内存保留1秒。
